# AssistantGM

Minimal Next.js App Router foundation for the NHL franchise-management assistant.

## Local commands

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Run checks:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Architecture and the active slice are described in `docs/architecture.md`; work is tracked in `docs/backlog.md`.
