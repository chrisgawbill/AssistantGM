# AssistantGM

Minimal Next.js App Router foundation for the NHL franchise-management assistant.

## Local commands

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Run checks:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

The app currently contains only a landing route and the initial source boundaries under `src/`.
